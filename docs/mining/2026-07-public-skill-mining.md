# Public Skill Mining — July 2026

This report records the public-facing result of the first-party skill mining
pass. The private ledger retains machine paths and source-level disposition;
this report uses logical source classes so it is safe to redistribute.

## Canonical Boundary

`jakyeamos-agent-skills` is the canonical catalog for portable, redistributable
skills. AIOS remains an archival/internal runtime source. Generated harvests,
runtime state, transcripts, credentials, caches, vendor-managed configuration,
and product-private workflows are not copied into this repository.

## Promoted Skills

The following behavior families are published as concise skills with supporting
workflow/reference material:

- `low-always-loaded-instruction-migration` — manifest-driven migration of
  multi-runtime instruction surfaces with explicit conflict and drift states.
- `skill-harvest-and-promotion` — harvest, gap analysis, redaction,
  skillification, forward testing, and promotion/defer decisions.
- `repo-behavior-spec-loop` — source-derived behavior inventory, canonical
  tabular specification, running-app verification, remediation, and regression
  evidence.
- `review-gated-verified-fix` — protected baseline, disposable execution,
  explicit gates, acceptance evidence, and human review handoff.
- `evidence-backed-change-surface-mapping` — bounded advisory impact mapping
  that preserves unknown paths, freshness, ownership, and provenance.
- `agentized-task-packet` — compilation of an ambiguous request into targeted
  context, constraints, verification, acceptance, and handoff fields.
- `durable-agent-workflows` — durable goals, workspaces, artifacts, steering,
  queueing, memory, and stopping conditions.
- `divergent-strategy` — candidate portfolios, independent judges, entropy, and
  approval-gated promotion of strategy artifacts.
- `operating-language` — canonical domain, architecture, and agent-control
  vocabulary with observable leading-word tests.

## Merged or Referenced

- Existing governed-work-loop, evaluation-evidence, repo-aware-context,
  environment-legibility-audit, safe-tool-guards, Terrace, and Research Domain
  Writing assets remain canonical where they already cover the behavior.
- Quality Runner, TMCP runtime, Pre-CR Suite, agent evaluation, context
  compiler, Greenlight, and related products remain external references or
  contract dependencies; their runtimes are not vendored.
- Orchestration, quality-gate, and offline-bootstrap details are supporting
  references where a new standalone skill would duplicate an existing public
  contract.

## Deferred or Excluded

- Donor-derived macOS material remains deferred until redistribution and
  attribution evidence is complete. No donor code or release side effects are
  copied.
- Product-specific, private-domain, personal-profile, legal, career, brand,
  host-control, generated, cache, transcript, credential, and vendor-managed
  material remains excluded.

## Evidence Labels

Public case studies distinguish observed behavior, mechanism, limitation, and
unmeasured hypothesis. A clean validator run proves catalog integrity; it does
not claim improved model quality or operational performance.
