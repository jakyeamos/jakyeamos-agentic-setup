This is a proposal-stage system map for the public Jakye Amos Agent Skills
repository. The public/private boundary, catalog, source files, schemas, and
verification evidence remain authoritative.

## Load order

1. Read `CONTEXT.md` for surface boundaries and projection gates.
2. Read `_meta/schema.md` before adding a card.
3. Use `objects/_index.md` to choose a bounded surface.
4. Verify source and manifest citations before claiming behavior.

No `processes/` or `effects/` shelf exists yet.

## Authority

- `.project-compass/` owns public JAS intent and child alignment.
- This map owns only the proposed file-backed structure.
