# Divergent Strategy

Use this workflow when the best strategy is uncertain and a small portfolio of alternatives can reveal a better direction.

## 1. Define the search

State the decision, constraints, budget, horizon, and promotion criteria. Generate a bounded candidate set with materially different assumptions. Do not create variations that differ only in wording or implementation trivia.

## 2. Judge explicitly

Use named judges such as user value, feasibility, evidence quality, reversibility, strategic fit, time, cost, risk, and coverage. When the decision supplies criteria, score every candidate against each supplied criterion and state the weighting or say that weights are equal; never invent a proxy score. Record the judge, evidence, uncertainty, and confidence for every meaningful score. Keep candidate generation separate from evaluation so early preference does not collapse the search.

## 3. Manage the portfolio

Maintain a portfolio of promising, uncertain, and rejected candidates. Measure entropy as the amount of meaningful uncertainty remaining, not as a decorative score. Spend more effort where evidence can change the decision; stop exploring when the promotion threshold is met or the budget is exhausted.

## 4. Promote and write back

Promote a candidate only when the evidence and decision rule support it. Record the promoted behavior, rejected alternatives, follow-up experiment, and owner. Write back only reviewed decisions and reusable patterns; never turn speculative candidates into default instructions.
