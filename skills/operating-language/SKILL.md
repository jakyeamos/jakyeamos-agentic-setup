# Operating Language

Use this skill to create or update a canonical operating-language artifact. It
is a behavioral control surface, not a glossary of every project noun.

## Contract

1. Extract domain, architecture, ownership, boundary, and quality terms from a
   targeted context set.
2. Find synonyms, overloaded terms, vague words, and repeated behavioral prose.
3. Apply the Leading Word Test: compact, pretrained, behavioral, reusable,
   observable, and non-overlapping.
4. Define a trigger and completion criterion for every agent-control term.
5. Record rejected terms, migration notes, relationships, and verification
   signals in the canonical artifact.

Reject words that sound good but do not change what an agent does.
