# Cursor adapter

Map the portable workflows to the repository-level instruction surface and
review any hook integration separately.

- Start with `repo-aware-context` and `governed-work-loop`.
- Stage the context-budget and tool-guard mappings rather than registering
  them automatically.
- Keep host-managed instructions and generated settings outside the portable
  package.
- Verify the mapped workflow in a disposable repository before using it on a
  live project.

This adapter is a behavioral mapping, not a copy of host-managed settings.
