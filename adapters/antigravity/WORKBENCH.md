# Antigravity adapter edge

This is sanitized, staged guidance for Antigravity. It is not a live host
instruction file, settings file, hook, or registration recipe.

- Route from the public router to the nearest repository context index.
- Load one matching workflow or skill only after its trigger is observed.
- Verify the host's documented project-instruction surface before manual
  registration; do not infer syntax from another runtime.
- Keep generated settings, credentials, login, and GUI-only setup outside the
  portable package.

Antigravity remains explicitly `unverified` until a supported runtime is
available for a non-destructive smoke check.
